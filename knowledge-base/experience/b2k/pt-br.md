## Descrição

Desenvolvimento de aplicativo para o setor agrícola

- Desenvolvi um aplicativo móvel multiplataforma com React Native, TypeScript e Expo, focado na gestão de equipamentos agrícolas.
- Implementei sistema de comunicação via Bluetooth para configuração e monitoramento remoto de dispositivos em campo.
- Criei dashboards interativos com gráficos para análise de horas trabalhadas, deslocamento e velocidade dos equipamentos.
- Desenvolvi funcionalidades de visualização em tempo real da localização e status dos equipamentos agrícolas.
- Implementei sistema robusto de sincronização de dados com suporte a operações offline, essencial para áreas rurais com conectividade limitada.
- Otimizei o desempenho do aplicativo para funcionar em diversos dispositivos, garantindo uma experiência fluida mesmo em hardware mais limitado.
