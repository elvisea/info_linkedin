# Projetos

Backup manual da seção **Projetos** do LinkedIn.

## Organização

| Regra                            | Detalhe                                                                                                                          |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **Um arquivo `.md` por projeto** | Nome do arquivo em minúsculas e hífens: `{slug}.md` (ex.: `go-happy.md`).                                                        |
| **Conteúdo**                     | Metadados (período, associação), descrição, links (layout web, mobile, plataforma etc.), competências, notas sobre mídia/anexos. |
| **Idioma**                       | Texto do perfil costuma estar em inglês; incluímos referência em PT quando fizer sentido no mesmo arquivo.                       |

**Links:** encurtadores (bit.ly) podem expirar ou mudar — alinhar com as observações em [certification/\_index.md](../certification/_index.md) (testar URLs; pasta pública Drive/Dropbox para recrutadores).
